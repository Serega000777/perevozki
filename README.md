# Perevozki

Самостоятельный Telegram Mini App + Telegram-бот для учёта автотехники и перевозок:
машины, ходки (рейсы) с оплатой, расходы по категориям, аналитика доходов и расходов.

Функционал выделен из раздела «Техника» проекта Cement CRM и живёт отдельно:
свой репозиторий, свой backend, своя база данных, свой бот и свой Docker-деплой.

> Проект в стадии bootstrap. Актуальное состояние — в [AGENT_DONE.md](AGENT_DONE.md),
