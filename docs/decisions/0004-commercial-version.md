# ADR 0004 — Коммерческая версия «Перевозчик»: мультиаккаунт и платежи

Дата: 2026-10-19 · Статус: **предложено** (ждёт решений владельца) · Автор: Claude Code (Windows)

## Задача владельца

Текущий Perevozki для своих двух машин (владелец вносит, остальные смотрят) **оставить как есть**.
Отдельно — попробовать зарабатывать: полноценный Telegram Mini App и приложения iOS/Android
(App Store, Google Play, RuStore), оплата звёздами в Telegram, через магазины и на внешнем сайте.

## Факты о платежах (проверено 2026-10-19, перед запуском перепроверить)

| Канал | Состояние для пользователей из России | Что нужно |
|---|---|---|
| Telegram Mini App | цифровые товары и подписки — через **Telegram Stars** (боты без Stars за цифровое Telegram блокировал в 2024) | бот, `createInvoiceLink` с валютой `XTR` и `subscription_period`; вывод — через Fragment (TON) |
| Сайт | карты, СБП, автосписания — ЮKassa / Т-Банк / CloudPayments | **ИП или ООО**, договор с эквайрингом, чеки по 54-ФЗ (сервис «Чеки от ЮKassa» или своя касса) |
| RuStore | платежи работают; с 1 февраля 2026 монетизация **только ИП/юрлицам**, самозанятые отключены; комиссия ~15% | аккаунт разработчика на ИП, RuStore Pay SDK |
| Google Play | оплата для пользователей из РФ приостановлена с марта 2022, сведений об отмене нет | бесплатное приложение; продажи — для зарубежных пользователей и зарубежного юрлица |
| App Store | Apple **остановила все платежи в России с 1 апреля 2026**; ранее возражала против упоминания внешней оплаты | бесплатное приложение без покупок внутри для РФ; Apple Developer $99/год (оплата из РФ затруднена) |

App Store и Google Play — для присутствия и входа в уже купленную подписку, без продаж внутри.

## Предлагаемое решение

1. **Два развёртывания из одного кода.** Текущий `perevozki.crm-cement.ru` + `@perevozki_bot_bot`
   не трогаем. Коммерческий «Перевозчик» — отдельный бот, домен, БД и **отдельный VPS** (общий
   слабый сервер с Amola уже зависал). Переключение — переменными окружения.
2. **Мультиаккаунт («автопарк»).** Таблица `Fleet` + `fleetId` у машин, ходок, расходов и
   категорий; `FleetMember` (владелец / редактор / зритель) и приглашение по ссылке — это та же
   механика «я вношу, другие видят», только у каждого клиента своя. Все запросы фильтруются по
   автопарку на сервере (тесты на изоляцию обязательны).
3. **Тарифы (предложение, решает владелец):** «Бесплатно» — 1 машина, история 2 месяца, 1 зритель;
   «Про» — без ограничений по машинам и истории, зрители, выгрузка в Excel, фото и документы машин,
   напоминания о ТО и страховке. Ориентир 299–490 ₽/мес или цена за машину.
4. **Права по подписке** — одна таблица `Subscription` (тариф, до какой даты, источник: stars /
   web / rustore). Любой канал оплаты продлевает одну и ту же подписку, вход на любом устройстве
   видит её.
5. **Приложения iOS/Android** — **Capacitor** поверх текущего React-кода (почти без переписывания).
   Вход вне Telegram: Telegram Login, телефон с кодом или e-mail. Альтернатива — переписать на
   React Native/Expo (как Amola): дольше, выигрыш небольшой.

## Этапы

| Этап | Что | Требует от владельца |
|---|---|---|
| 1 | Мультиаккаунт, приглашения, лимиты, онбординг; новый бот; оплата **Stars** | новый бот, домен, VPS, тарифы |
| 2 | Сайт-лендинг + личный кабинет + оплата **ЮKassa** (автосписания, чеки) | ИП, расчётный счёт, договор ЮKassa, оферта, политика ПДн |
| 3 | Android-приложение (Capacitor) в **RuStore** с RuStore Pay | аккаунт разработчика RuStore на ИП |
| 4 | Android в Google Play и iOS в App Store — бесплатные, вход в подписку, без продаж внутри | аккаунты Google ($25) и Apple ($99/год) |

## Юридическое (кратко)

ИП на УСН 6% вместо самозанятости: самозанятых отключили в RuStore, а у эквайринга и для
автосписаний ИП проще. Нужны оферта, политика обработки персональных данных (152-ФЗ, уведомление
в Роскомнадзор как оператора ПДн), чеки по 54-ФЗ. Доход в Stars выводится через TON — с налоговой
стороны стоит проконсультироваться с бухгалтером.

## Альтернативы

- Продавать прямо в текущем развёртывании — отклонено: смешает ваши данные с клиентскими и рискует
  общим VPS.
- Только Telegram без приложений — быстрее и дешевле; приложения можно добавить позже без
  переделки, если сделать вход вне Telegram сразу на этапе 2.
