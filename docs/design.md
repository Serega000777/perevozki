# Дизайн Perevozki («Перевозчик») — правила

Обновлено: 2026-10-19 · Claude Code (Windows).

**Источник правды — референсы владельца от 2026-10-19** (четыре экрана: Авто, Рейсы (до 2026-10-30 — «Ходки»), Расходы,
Аналитика; переданы в чат, в репозитории их нет). Владелец попросил повторить их «один в один»;
прежние правила «без признаков ИИ-дизайна» этим решением заменены. Код: стили —
`frontend/src/styles.css`, компоненты — `frontend/src/equipment/ui.tsx`, графика бренда —
`frontend/src/brand.tsx`, графики — `frontend/src/equipment/charts.tsx`.

## Общее для всех экранов

- Фон кремовый (`--bg #fbf9ea`, сверху теплее), карточки белые, радиус 20, тонкая рамка `--line`.
- Шапка `PageHeader`: логотип владельца (`perevozchik-logo.svg` от 2026-10-30: лаймовый квадрат,
  тёмная арка с дорогой; углы скруглены) + «ПЕРЕВОЗЧИК», кнопка меню справа, крупный заголовок
  «Перевозки», подзаголовок своей вкладки, справа иллюстрация (`HeroArt`: бледные дорога, горы и
  ели, на их фоне фура владельца — картинка `src/assets/hero-truck.webp` (прислал владелец 2026-10-30,
  прозрачный фон, 900px, 41 КБ). Подзаголовок `.lead` уже ширины шапки, чтобы не заходить под фуру.
- Вкладки с иконками (Truck, Route, Fuel, ChartNoAxesColumn): выбранная — чёрная.
- Под вкладками — полоса из трёх показателей `Stats` (иконка на бледно-лаймовой подложке, число,
  подпись). Аналитика показывает итоги **за всё время**.
- Формы — в `Card` с иконкой и заголовком; кнопка добавления чёрная с белым кружком «+»
  (у «Сохранить» в правке «+» нет).
- Выбор машины — прямоугольные кнопки (радиус 11), категории — скруглённые (14), даты —
  «таблетки» (999), день последней добавленной записи — сплошной лайм.
- Переключатель «получены» во включённом виде лаймовый.

## Экраны

- **Авто:** карточка «Новая машина» свёрнута — подсказка и кнопка «Добавить машину», форма
  открывается в шторке (она длинная). В форме — превью (своё фото или картинка вида),
  «Загрузить фото», вид техники, марка, модель (подсказки из `catalog.ts`), название, госномер и
  свёрнутая строка «Марки — товарные знаки их правообладателей». Карточки машин — фото или картинка
  по виду техники (`VehicleArt`, 29 видов) с надписью марки (наш шрифт,
  **не логотип**), название, «вид · марка модель · госномер», «Активна», число рейсов, стрелка.
- **Картинки техники** — пак владельца от 2026-10-30 (`src/assets/vehicles/<вид>.webp`, имя файла =
  ключ вида из `KINDS`): прозрачный фон, обрезаны по краям, до 640×400, WebP ~20–65 КБ; в карточке
  `object-fit: contain`. Грузятся отдельными файлами, только видимые. Новый вид — ключ в `KINDS` и
  файл с тем же именем. Картинки без логотипов марок — так и держать.
- **Рейсы:** каждый рейс — своя карточка: дата над направлением, сумма, плашка
  «✓ Оплачено» / «⏱ Ожидает» (нажатие переключает), стрелка → правка. При «Все машины» —
  блоки по машинам (заголовок с итогом), внутри по датам.
- **Расходы:** белый блок на машину, внутри серые полосы дней с суммой; строка — иконка категории
  (`CategoryIcon`), категория, комментарий серым, сумма, стрелка. Ниже — карточка категорий.
- **Аналитика:** сверху за всё время — выручка, прибыль, баланс. «Обзор за …» (выбор машины,
  периоды; значок календаря открывает шторку-календарь `RangeCalendar`: первый и последний день
  касанием), под периодами — подпись диапазона («19–25 октября»), линия
  выручки (`LineChart`: неделя — по дням, месяц — по неделям, всё время — по месяцам), метрики
  (средний рейс, расход на рейс, маржа); 4 тёмные плитки (как раньше, крупнее); «По технике»;
  «Расходы по категориям» (кольцо `Donut`, ≤5 сегментов) и «По машинам»; «Итоги» (самая
  прибыльная, лучший месяц). Нажатия ведут в прежние разбивки-шторки.

## Узкие экраны (адаптация, которой нет на референсах)

Референсы нарисованы примерно на 470px. На 375–440px: вкладки — иконка над подписью; в
показателях и метриках иконка над числом (≤520px); сумма рейса над плашкой статуса; на ≤520px
выбор машины и календарь в первом ряду, периоды — во втором; «Расходы по категориям» и «По
машинам» рядом только с 600px. Перед выкладкой проверять 375, 400 и 470px.
